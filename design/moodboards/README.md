## How to use these packs

1. **Before wireframes (Phase 3):** read AD review Q1–Q12, then the theme card you are drawing.  
2. **Each theme is an object fiction** — housing, glass, meters, type tech. Palette alone is not a theme.  
3. **Hero object** on Now Playing is mandatory; if it is missing, the board failed.  
4. **Viz language** must match the card (needles / LED / VFD / scope / rain / etc.) — never generic UI bars.  
5. **Anti-copy notes** are rejection criteria for reviews and future implementation.  
6. **Composition zones** are textual layout contracts for 480×272 — not code.  
7. **Shared finish vocabulary** (brushed, ABS, smoked glass, acrylic, rubber, carbon, anodized) is shared; **compositions are unique**.  
8. **Exhibition readability** overrides microscopic authenticity on contrast and label size.
