## Глобальный тон пакета

Каждая тема — **отдельный промышленный / коллекционный объект**, поставленный на барную стойку PlayStation Experience. Зритель на расстоянии вытянутой руки должен узнать устройство за долю секунды: корпус, стекло, метры, шрифт дисплея. Палитра обслуживает материал, а не заменяет его.

**Shared finish vocabulary (из AD Q8):** brushed metal grain, matte ABS, smoked/tinted glass, acrylic lens edge, soft rubber (TPE), carbon/textured polymer, anodized aluminum. Specular = prebaked 2–3 stop. Glow budget = 1–2 additive layers.

**Motion ceiling (AD Q11):** alive but calm. BGV never louder than title + meters.

# Theme 1 — Sony Walkman Premium

### Color palette

| Hex | Role |
|-----|------|
| `#1A1C1E` | matte black polymer frame / body shadow |
| `#8A9096` | brushed aluminum mid |
| `#C8CED4` | brushed aluminum hi / mirror lid catch |
| `#4A4E52` | soft grey rubber edge band |
| `#0B0E10` | smoked acrylic LCD / door well |
| `#D4A020` → `#FF9A1A` | EL remote amber/orange glow (accent) |
| `#2A6B9A` | optional secondary EL blue (status only) |
| `#E8ECEF` | segment LCD lit digits |
| `#3D4248` | segment LCD unlit ghosts |

### Style & atmosphere

Премиальный карманный Hi-Fi конца EX-эры: тонкий, серьёзный, «взрослый» Walkman на барной стойке выставки Sony, а не fashion NW. Корпус читается как магниево-алюминиевый industrial object — зеркальная дверь кассеты или приоткрытое окно с лёгким shimmer, резиновый кант по ребру, тихий embossed логотип. Оранжевое EL живёт **только** на remote-zone (левая или нижняя «палочка»), как ювелирная подсветка пульта, а не как заливка фейсплейта.

### Materials list

- Mirror / chrome-plated cassette door (or open smoked window)  
- Brushed Al-Mg lid grain (directional)  
- Matte black / gunmetal polymer chassis  
- Soft grey rubber (TPE) edge band  
- Acrylic polarizing-tinted LCD window  
- Plastic remote stick with EL panel behind legend print  

### Typography / display tech

Segment / small LCD digits; condensed track line in remote or under-window strip. Thin industrial Latin; optional micro Japanese later. No huge centered sans headline.

### Animation vocabulary

- Slow EL breathe on remote (1–2 Hz soft)  
- Cassette-window shimmer or 2–4 frame reel hint if door open  
- Mega Bass LED ladder peak-fast  
- Seek as physical thin slider travel  
- Tempo: lounge Hi-Fi, almost silent confidence  

### Visual language keywords

industrial · slim-strong · mirror door · remote jewelry · quiet Sony · EX black/silver · arm’s-length premium  

### Inspiration anchors

WM-EX808HG · WM-EX5 (mirror door + RM-WM71EL) · WM-EX90 · late EX921 jog-lever  

### Signature hero object (Now Playing)

**Mirror cassette door / open cassette window** + **EL remote strip** as twin signatures.

### Viz / meter language

Mega Bass–style **LED ladder** (green→yellow→amber segments); tiny stereo LEDs. Not phone waveform.

### Anti-copy notes

❌ Pastel pink NW fashion chrome · ❌ full-screen orange glow · ❌ floating FABs / card carousel · ❌ phone top app bar · ❌ flat silver rectangle labeled “Walkman”

### Composition intent @ 480×272

| Zone | Placement |
|------|-----------|
| **Hero** | Upper-center cassette door/window (~40–50% width) |
| **LCD** | Under window strip and/or left remote EL panel |
| **Transport** | Bottom-center / bottom-right cluster (physical key row) |
| **Meters** | Near remote or under LCD — LED ladder |
| **Status** | Top-left quiet wordmark/engraving; battery/hold micro on remote |

**Cover art:** No (AD Q9). Cassette fiction is the art.

Main window сохраняет классические пропорции, вписанный в 480×272 как объект на рабочем столе Win98/XP. Металл с тремя ступенями bevel, тёмный колодец LCD, оранжевая «таблетка» seek, зелёный фосфор цифр. Ценность — texture craft, не изобретение layout.

### Materials list

- Dark recessed LCD well (almost CRT paint)  
- Orange molded plastic seek thumb  
- Subtle noise / brushed fill (not flat `#808080`)  
- Playlist chrome as thinner metal surround  

### Typography / display tech

Bitmap LCD digit font (Numbers.bmp DNA); tiny monospace track; MONO/STEREO lamps.

### Animation vocabulary

- Classic peak spectrum bars with peak-hold dots  
- Play/pause sprite flip  
- Seek knob travel  
- Optional EQ spline only in EQ mode  
- Tempo: snappy desktop utility, not cinematic  

### Visual language keywords

collectible skin · bevel metal · green LCD · orange seek · classic slots · Nullsoft DNA  

### Inspiration anchors

Winamp 2.x Base Skin · cult metal/LCD skins · AIMP Classic / WMP9 remakes (secondary)  

### Signature hero object (Now Playing)

**Inset Main window** (titlebar → LCD → spectrum → posbar → cbuttons) as the collectible object.

### Viz / meter language

**Peak spectrum analyzer bars** (8–16), green→yellow→red, peak hold. Stereo LED pair.

### Anti-copy notes

❌ Stretch Main to fullscreen 480×272 · ❌ album-art full bleed hero · ❌ huge circular play · ❌ Material progress bar · ❌ “Winamp colors” on phone layout  

### Composition intent @ 480×272

| Zone | Placement |
|------|-----------|
| **Hero** | Main window upper-left or top-center (~classic aspect scaled) |
| **LCD** | Inside Main — time + track |
| **Transport** | Cbuttons row inside Main |
| **Meters** | Spectrum band inside Main |
| **Status** | Mono/stereo + shuf/rep; playlist strip right or below fills remainder |

**Cover art:** No.

### Inspiration anchors
